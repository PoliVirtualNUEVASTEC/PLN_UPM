# M11 — Banco de pruebas y metricas

Escena de escritorio, **sin VR**, donde se escribe una frase por teclado y se ve en pantalla:

- intencion clasificada y confianza,
- estado de receptividad y la razon del ultimo cambio,
- respuesta generada,
- latencia de cada etapa.

Se arma contra los **dobles** de cada modulo y se van reemplazando por implementaciones reales de a uno.
En el Sprint 13-14 se convierte en el instrumento de medicion del Objetivo 4.
